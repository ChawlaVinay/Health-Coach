# Health Coach: setup

1. Supabase: open SQL Editor, paste supabase.sql, run it.
2. Supabase: Project Settings > API. Copy the Project URL and the anon key into config.js (never the service_role key).
3. Netlify: Add new site > Deploy manually. Drag this unzipped folder in.
4. Supabase: Authentication > URL Configuration. Set Site URL to your Netlify address.
5. Open your Netlify address, tap Create account, confirm the email, sign in.
6. After your account exists, turn off new signups in Supabase Authentication settings so only you can sign in.
7. Phone: open the site, then Add to Home Screen.
8. Me tab: add your Diwali and travel dates, then download the reminders file and open it on your phone.
